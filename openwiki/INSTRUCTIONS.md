CodeRecall 저장소의 코드 위키입니다. GitHub 커밋을 플래시카드로 만들어 복습하게 하는 서비스이고, React 18과 Vite 기반 프론트엔드(`app/`), Firebase Cloud Functions(`functions/`), Firestore 보안 규칙(`firestore.rules`)으로 이루어져 있습니다.

# 언어

- 모든 페이지는 한국어로 씁니다. 코드, 파일 경로, 명령어, 고유 명사는 원문을 유지합니다.

# 우선순위

코드를 그대로 옮긴 설명보다 코드만 읽어서는 알기 어려운 내용을 먼저 씁니다.

1. 왜 이렇게 만들었는가: 설계 의도, 버린 대안, 감수한 점
2. 여러 곳을 함께 바꿔야 하는 값과 규칙: 예를 들어 프론트엔드와 Functions에 같은 상한이 있는 경우
3. 보안과 비용 경계: Firestore 규칙, 공개 AI 함수 호출 상한, 서버 전용 컬렉션
4. 주요 흐름: 플래시카드 생성 경로, 사전 생성 스케줄, 푸시 알림
5. 진입점, 모듈 지도, 로컬 실행과 배포 절차

함수 시그니처 목록이나 커밋 이력만으로 충분한 변경 내용은 쓰지 않습니다.

# 원본과 근거

- `docs/adr/`는 사람이 쓴 결정 기록(ADR)이고 결정의 정본입니다. 이 파일들은 고치지 않습니다. 결정의 이유를 설명할 때는 ADR을 근거로 삼고 링크합니다. ADR과 코드가 어긋나면 위키에 어긋남을 적고 ADR은 그대로 둡니다.
- `AGENTS.md`, `.github/CONTRIBUTING.md`, `design-system/`도 근거로 읽습니다.
- git 이력과 PR 제목(`feat(번호): ...`)으로 변경 배경을 확인합니다.

# 페이지 구성

- 기존 디렉터리 구성(`architecture/`, `flashcard/`)을 유지하고, 새 주제는 같은 방식의 주제별 하위 디렉터리로 추가합니다.
- 기존 페이지의 본문에 담긴 설계 의도는 코드와 맞는 한 보존하고 보강합니다. 사람이 쓴 이유를 요약 과정에서 지우지 않습니다.
- 결정의 이유를 다루는 페이지는 ADR 내용을 다시 쓰지 말고 요약한 뒤 해당 ADR을 링크합니다.

# 쓰지 않는 내용

저장소가 public입니다. 비밀 값, API 키, 비용과 매출 수치, 사용자 개인정보, 운영 계정 정보는 어떤 페이지에도 쓰지 않습니다. 환경 변수는 이름과 용도만 적고 값은 적지 않습니다.
