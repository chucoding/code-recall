# 파일

- [플래시카드 덱 문서 크기 예산](deck-size-budget.md) - 한 날짜 문서에 함께 저장되는 한국어·영어 플래시카드 덱의 바이트 예산, 축소 순서, 남은 예산 계산을 설명한다. 앱과 Cloud Functions의 중복 구현 계약 및 별도 공개 데모 캐시의 제한도 다룬다.
- [플래시카드 생성·번역·재생성 경로](generation-paths.md) - 오늘의 사용자 덱이 사전 생성 덱 조회, 반대 언어 덱 번역, 클라이언트 즉석 생성으로 분기되는 순서와 랜딩 데모 캐시 경로를 설명한다. GitHub diff·AI 호출·저장·실패 격리의 공통 계약과 경로별 차이를 정리한다.
- [사용자 덱 사전 생성](pregeneration.md) - 시간대별 스케줄러가 최근 활동 사용자의 오늘 플래시카드 덱을 Cloud Tasks로 미리 생성하는 워크플로를 설명한다. 완료 기록, 트랜잭션 경쟁 방지, 확정 실패와 일시 실패의 재시도 경계를 다룬다.
