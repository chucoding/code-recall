# 파일

- [덱 문서 크기 예산](deck-size-budget.md) - 한 날짜의 한국어·영어 플래시카드 덱을 하나의 Firestore 문서에 저장할 때 적용하는 바이트 예산과 축소 계약을 설명한다. 앱 실시간 생성과 서버 사전 생성이 같은 저장 규칙을 유지하는 방법과 예산 보장의 범위를 다룬다.
- [카드 생성 경로](generation-paths.md) - 즉시 생성, 사용자별 사전 생성, 랜딩 데모 캐시가 GitHub 변경을 카드 덱으로 만드는 공통 계약과 경로별 저장·실패 처리를 설명한다.
- [오늘의 플래시카드 사전 생성](pregeneration.md) - 사용자의 시간대에서 새 날짜가 된 뒤 최근 활동 사용자의 오늘 덱을 Cloud Tasks로 준비하는 서버 워크플로다. 대상 선정, 앱과의 저장 경쟁, 완료 기록과 재시도 경계를 설명한다.
