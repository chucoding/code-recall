# 파일

- [일별 덱 크기 예산](deck-size-budget.md) - 하나의 Firestore 날짜 문서에서 한국어·영어 플래시카드 덱이 공유하는 바이트 예산과 저장 전 축소 계약을 설명한다. 앱과 Cloud Functions의 복제 구현을 안전하게 함께 변경하고 검증하는 기준을 제공한다.
- [플래시카드 생성 경로](generation-paths.md) - 오늘의 덱이 캐시 읽기, 반대 언어 번역, 브라우저 즉시 생성, 서버 사전 생성으로 갈라지는 조건을 설명한다. GitHub 커밋에서 AI 카드 생성과 Firestore 저장으로 이어지는 공통 계약 및 실패 폴백을 다룬다.
- [사용자 덱 사전 생성](pregeneration.md) - 사용자 타임존의 새벽에 최근 활동 사용자의 오늘 덱을 Cloud Tasks로 생성해 첫 화면의 GitHub·AI 대기를 줄이는 서버 워크플로를 설명한다. 대상 선정, 앱과의 저장 경쟁, 완료 기록 및 재시도 경계를 다룬다.
